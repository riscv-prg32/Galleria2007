# Reproducing the Galleria 2007 cartridges

This guide rebuilds, from a clean machine, the exact artefacts published in
`dist/`: four cartridges (Italian and English editions × ESP32-C6 and QEMU)
and two Cartridge Store bundles, and re-runs every check. The build is
**deterministic**: following it with the same tool versions reproduces the
checksums in `dist/SHA256SUMS` byte for byte (verified twice on 2026-10-01).

If you want to *adapt* the project into a new cartridge instead, read
[replicate.md](replicate.md).

## 1. Reference environment

| Component | Version used for release 0.1.0 | Notes |
|---|---|---|
| OS | macOS 26 (Apple Silicon) | Linux works for everything except the iOS runner |
| PRG32 | `riscv-prg32/PRG32` `main` @ `a8669e5` | cartridge builder, ABI headers, Store tools (`687251f` produces identical bytes) |
| ESP-IDF | v5.4 | provides the toolchain |
| RISC-V toolchain | `riscv32-esp-elf-gcc` esp-14.2.0_20241119 (GCC 14.2.0) | compiler version changes code bytes |
| Espressif QEMU | `qemu-riscv32` esp_develop_9.0.0_20240606 | QEMU runs only |
| Python | 3.12 (any 3.9+) with Pillow 11 | generators, store art, QEMU runner |
| ffmpeg | 7 or newer | 30-second preview video only |
| CMake + Ninja | 3.21+ | PRG32-QT headless runner only |
| Swift | 6.x (Xcode command-line tools) | PRG32-iOS headless runner only |
| CartridgeStore | `riscv-prg32/CartridgeStore` @ `212e060` | bundle validation only |
| PRG32-QT | `riscv-prg32/PRG32-QT` @ `d2f139b` | host compatibility check, performance model |
| PRG32-iOS | `riscv-prg32/PRG32-iOS` @ `f0c1cdb` | host compatibility check |

Only PRG32 + ESP-IDF + Python/Pillow are needed to build the cartridges; the
rest is for verification.

## 2. Directory layout

All repositories are siblings (the scripts find them by default; each can be
overridden with an environment variable):

```text
riscv-prg32/
├── Galleria2007/        this repository
├── PRG32/               PRG32_REPO
├── CartridgeStore/      CARTRIDGE_STORE_REPO   (optional)
├── PRG32-QT/            PRG32_QT_REPO          (optional)
└── PRG32-iOS/           PRG32_IOS_REPO         (optional)
```

```bash
mkdir -p riscv-prg32 && cd riscv-prg32
git clone https://github.com/riscv-prg32/Galleria2007
git clone https://github.com/riscv-prg32/PRG32
git -C PRG32 checkout a8669e5          # the release reference (or a newer main)
git clone https://github.com/riscv-prg32/CartridgeStore     # optional
git clone https://github.com/riscv-prg32/PRG32-QT           # optional
git clone https://github.com/riscv-prg32/PRG32-iOS          # optional
```

## 3. Toolchain

Install ESP-IDF 5.4 for `esp32c3,esp32c6` and Espressif QEMU as described in
the PRG32 [getting-started guide](https://github.com/riscv-prg32/PRG32/blob/main/docs/usage/getting_started.md):

```bash
cd ~/esp-idf && ./install.sh esp32c3,esp32c6
python3 ~/esp-idf/tools/idf_tools.py install qemu-riscv32
python3 -m pip install --user Pillow
```

`scripts/build.sh` sources `~/esp-idf/export.sh` by itself when
`riscv32-esp-elf-gcc` is not on `PATH` (override with `IDF_EXPORT`).

> The ESP-IDF virtual environment's `python3` usually lacks Pillow. Run the
> host tests, `tools/make_store_art.py` and `scripts/qemu_preview.py` from a
> shell where ESP-IDF is **not** sourced; `scripts/build.sh` only needs Pillow
> for optional previews.

## 4. Host tests (no ESP-IDF needed)

```bash
cd Galleria2007
tests/run_tests.sh shots
```

Expected: every suite reports `0 failures` (fixed-point, world, inventory,
AI, protocol, input, and the gameplay suite once per language, which plays
the whole vertical slice solo), and `build/shots/<lang>/*.png` are written.

## 5. Generated sources (optional: they are committed)

Every derived file is regenerated by deterministic tools; `scripts/build.sh`
runs most of them. To regenerate everything by hand:

```bash
python3 tools/build_ids.py        # src/gen/ids.h        <- tools/g2007_ids.py
python3 tools/build_map.py        # src/gen/map_data.h   <- assets/map/galleria2007.json
python3 tools/build_assets.py     # textures, ramps, sprites, trig, lighting tables
python3 tools/build_strings.py    # src/gen/strings_<lang>.h <- lang/*.json
python3 tools/build_audio.py      # audio/audio.json, src/gen/audio_ids.h
python3 tools/build_font.py       # src/gen/font8.h      <- PRG32 firmware font
python3 tools/make_store_art.py   # assets/store/{icon,screenshot-<lang>}.png (after tests/run_tests.sh shots)
git status --short src/gen audio assets   # nothing should change
```

## 6. Build the cartridges

```bash
scripts/build.sh                     # it+en × esp32c6+qemu
```

For each edition and target the script:

1. regenerates sources and validates assets (palette indices, provenance,
   Store art size);
2. packs the AUD0 audio block with PRG32's `tools/prg32audio_pack.py`;
3. writes a two-line wrapper selecting the language and proves position
   independence (`tools/check_relocatable.py`);
4. builds a **portable** cartridge (`--portable`, `--required-feature sprites`,
   optional `multiplayer`, `audio`, `audio_plus`, `--cart-ram-kib 64`);
5. attaches metadata, icon, screenshot and colophon for the architecture;
6. enforces the three budgets (package ≤ 65,536; executable RAM ≤ 65,536;
   QEMU load image ≤ ~54,500) and writes summaries, metadata dumps and
   `dist/SHA256SUMS`.

Expected output (release 0.1.0):

```text
dist/galleria2007-en-esp32c6.prg32: package 54616/65536, RAM 57568/65536, load ~44924/54500
dist/galleria2007-en-qemu.prg32:    package 54614/65536, RAM 57568/65536, load ~44924/54500
dist/galleria2007-it-esp32c6.prg32: package 54893/65536, RAM 57756/65536, load ~45112/54500
dist/galleria2007-it-qemu.prg32:    package 54891/65536, RAM 57756/65536, load ~45112/54500
```

Build a subset with `LANGS="it" scripts/build.sh qemu`.

## 7. Pack and validate the Store bundles

```bash
# Optional but recommended: the Store's own ingestion code.
python3 -m venv ~/.venvs/cartridgestore
~/.venvs/cartridgestore/bin/pip install -r ../CartridgeStore/requirements.txt   # python3-saml may be skipped
STORE_PYTHON=~/.venvs/cartridgestore/bin/python scripts/pack-store-bundle.sh
```

Expected:

```text
esp32c6  galleria2007-it-esp32c6.prg32  54789 bytes (+10747 free) OK [store-ingest]
qemu     galleria2007-it-qemu.prg32     54787 bytes (+10749 free) OK [store-ingest]
galleria2007-it-0.1.0-store.zip: READY for submission (store-ingest)
```

`[store-ingest]` means the bundle went through CartridgeStore's
`_prepare_bundle()`, the code behind `POST /api/publish/bundle`. Without the
Store's Python requirements the validator falls back to its format module
(`[store-format]`) or to structural checks (`[structural]`).

## 8. Verify the checksums

```bash
cd dist && shasum -a 256 -c SHA256SUMS
```

Cartridges are reproducible because the generators use fixed seeds, the
compiler is pinned, and metadata timestamps are fixed. Bundles are
reproducible because `pack-store-bundle.sh` pins ZIP entry timestamps to the
release date (`updated_at` in the metadata).

## 9. Run on every host

```bash
scripts/check_hosts.sh
```

| Host | How it is exercised | Expected |
|---|---|---|
| any load address | `tools/check_relocatable.py` links at two addresses | `position independent` |
| PRG32-QT | builds the Qt-free `prg32qt-headless`, 300 scripted frames | `OK (300 frames) MEDIA graphics_non_black=…` |
| PRG32-iOS | `tools/ios-headless` on the unmodified `PRG32Core` package | `OK on PRG32-iOS core` |
| QEMU firmware | `scripts/qemu_preview.py --script smoke` | `loaded cartridge 'galleria2007-…'` |
| ESP32-C6 | by hand, see below | |

The QEMU firmware must exist in `../PRG32/build-qemu` (`python3 -m prg32 qemu
build` in the PRG32 checkout). At PRG32 `687251f` that build fails in
`prg32_store.c` (`esp_crt_bundle.h` not found), and `a8669e5` does not touch
that code; a firmware built from an earlier commit with the same ABI hash
(`0x260f6136`) works unchanged.

### Interactive QEMU

```bash
cd ../PRG32
python3 -m prg32 qemu upload ../Galleria2007/dist/galleria2007-it-qemu.prg32
python3 -m prg32 qemu run
```

Keys: arrows/WASD, `J`/`Z` = A, `K`/`X` = B, `J` then `K` quickly = A+B,
Enter = START.

### ESP32-C6 board

Flash the PRG32 firmware (`python3 -m prg32 esp32c6 build-and-flash` in the
PRG32 checkout), join its Wi-Fi, then:

```bash
python3 -m prg32 esp32c6 upload ../Galleria2007/dist/galleria2007-it-esp32c6.prg32 --url http://192.168.4.1
```

Record the results in [acceptance.md](acceptance.md).

## 10. Performance table

```bash
scripts/perf.sh
```

Builds six test-scene cartridges and prints instructions and modelled
milliseconds per frame on the PRG32-QT ESP32-C6 profile (expected averages
for this release: 12.3 ms per full-resolution frame, 7.2 ms per moving
frame). See [performance.md](performance.md).

## 11. Screenshots and the 30-second preview

```bash
tests/run_tests.sh shots                          # build/shots/<lang>/*.png
python3 tools/make_store_art.py                   # assets/store/*.png
scripts/qemu_preview.py --script preview --video --out build/qemu-preview
python3 ../PRG32/tools/validate_cartridge_media.py assets/store/screenshot-it.png build/qemu-preview/preview.mp4
ffmpeg -y -i build/qemu-preview/preview.mp4 -c:v libx264 -crf 28 -preset slow \
  -pix_fmt yuv420p -c:a aac -b:a 64k assets/store/preview-it.mp4
```

The preview is real QEMU gameplay (framebuffer dumped through QMP) with the
firmware's own audio stream; video frames differ between runs because of
emulator timing, so the MP4 is not part of the checksum list.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `riscv32-esp-elf-gcc not found` | source `~/esp-idf/export.sh` or set `IDF_EXPORT` |
| `ModuleNotFoundError: PIL` | run outside the ESP-IDF venv, or `pip install Pillow` in it |
| `cartridge needs N bytes, runtime has 32768` | old PRG32 checkout: `tools/prg32_cli.py` raises the host check to 64 KiB automatically; otherwise update PRG32 |
| `manifest.abi must be prg32-metadata-1.0` from the Store | an old bundle; re-run `scripts/pack-store-bundle.sh` |
| `Cartridge requires unavailable features 0x00000004` on iOS | a build that *requires* multiplayer; rebuild with this repository's `scripts/build.sh` |
| different checksums | a different compiler or PRG32 builder version; compare `build/*.summary.txt` |
| QEMU shows the PRG32 setup screen | the flash image has other cartridges: `qemu_preview.py` uses a fresh copy with only this one |
